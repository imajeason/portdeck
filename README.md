# 🎉 PortDeck v1.0.0 正式发布

> **PortDeck** 是一款轻量级、开箱即用的一站式 NAS 容器管理与导航工具。通过原生 SSH 协议与目标服务器通讯，无需在宿主机安装额外 Agent，零侵入、不篡改系统配置，为你提供直观且高效的 Docker 管理体验^^。

### ✨ 核心特性

#### 🛠️ 原生 SSH 无痕接入

* **零侵入架构** ：完全基于 SSH 协议执行 Docker 指令，无需在 NAS 安装任何第三方 Agent 服务，保障系统纯净与安全^^。

#### 🛒 应用市场与一键部署 (App Store)

* **开箱即用模板** ：内置丰富应用模板（影音媒体、工具、生产力、系统等）^^。
* **图形化参数配置** ：无需手动编写复杂的 `docker-compose.yml`，通过表单即可配置端口、路径与环境变量^^。
* **部署日志透明** ：提供实时部署日志输出与环境预检，部署过程清晰明了^^。

#### 🧭 智能可视化导航页

* **服务快速直达** ：集中呈现容器 Web 服务入口，方便快速跳转^^。
* **右键一键生成** ：在容器列表中右键选择“添加到导航页”，自动生成关联图标与访问链接^^。

#### 📦 容器全生命周期管理

* **Stack 聚合视图** ：支持 Compose Stack 分组展示与多容器关联管理^^。
* **全套控制与重构** ：支持启动、停止、重启、销毁及编辑配置后一键重构容器^^。
* **深度运维诊断** ：集成 Web Shell 终端、实时运行状态监控 (Stats)、配置 Inspect 查询与 Logs 日志查看^^。

#### 🌐 镜像、数据卷与网络治理

* **镜像中心** ：支持镜像搜索、拉取下载以及基于镜像直接创建容器^^。
* **资源清理与维护** ：直观展示 Docker Volumes（数据卷）与自定义 Network（Bridge / Host / Macvlan 等）^^。

#### ⚡ 官方镜像加速源

* 内置可选的高速 Docker 镜像加速源，轻松应对复杂网络环境下的镜像拉取难题^^。

### 💡 费用与使用说明

* **基础功能** ：面向个人用户 **全部免费** ，注册账号后即可体验完整 Docker 管理及应用市场部署功能^^。
* **加速源服务** ：由于带宽与节点存在固定成本，全局“镜像加速源”为可选付费项^^。除此之外无任何隐藏收费项目，请放心使用^^。
